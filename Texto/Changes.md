# Registro de cambios

Este archivo documenta los cambios importantes que se han hecho en el proyecto.  
Cada entrada indica la fecha, quién hizo el cambio y qué se modificó.  

**Instrucciones para logear:**

- Añade un nuevo bloque con la fecha del día cuando hagas cambios.  
- Describe brevemente qué hiciste y quién lo hizo.  
- Usa viñetas para separar cada cambio dentro de la fecha.  
- Mantén el formato simple y claro para que cualquiera pueda seguir el historial.

**Dudas de como ordenar**

- Si tienes dudas de como funcionan los .md ve al archivo `Glosario.md` alli tienes informacion para dejar el texto lindo
